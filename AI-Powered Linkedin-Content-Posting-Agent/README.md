# AI-Powered LinkedIn Content Posting Agent
An AI-powere LinkeIn content publishing automation built with n8n, Ollama, Qwen3, and the LinkedIn API
## Overview
This workflow automates the process of creating and publishing LinkedIn posts from a provided design asset and post information.
The workflow uses a local AI model through ollama to generate a professional LinkedIn caption, processes the accompanying design
image, uploads the image through the LinkedIn APII, prepares the final post, and publishes it automatically. The goal of the project
is to demonstrate how AI ca be integrated into a practical automation workflow to reduce repetitive content publishing tasks while 
keeping the creative direction under human control.
### Workflow
Start LinkedIn AI Agent
Set post details
Ollama AI Content Generator
Format LinkedIn Content
LinkedIn Initialize Image Upload
Marge
Upload Design to LinkedIn
LinkedIn Post Successfully

#### Use Case
This workflow can be adapted for designers, creators, marketers, agencies, and businesses that regularly publish visual content on LinkedIn.
Instead of manually preparing a caption, uploading an image, and publishing the post, the automation handles the repetitive technical steps
while allowing the user to control the creative inout.
